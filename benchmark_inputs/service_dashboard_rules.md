# 서비스 요청 대시보드 규칙

- 입력 CSV의 모든 행과 원문을 보존한다.
- 상태는 `open`, `in_progress`, `blocked`, `done` 네 값만 유효하다.
- 기준일은 2026-08-10이다.
- 완료되지 않았고 due_date가 기준일보다 이전이면 `overdue`로 표시한다.
- 임의의 우선순위 점수나 예측값을 만들지 않는다.
- 담당자, 상태, 카테고리 필터를 제공한다.
- 필터와 요약 카드의 수치는 같은 행 집합을 사용해야 한다.
- 정적 입력 자료만으로 완전히 동작해야 하며 모의 API나 외부 계정은 필요하지 않다.
