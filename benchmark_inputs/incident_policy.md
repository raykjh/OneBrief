# 고객 장애 대응 규칙

- 적용 대상: 고객이 사용하는 운영 서비스의 장애와 성능 저하
- 심각도 P1: 전체 서비스 중단, 데이터 손실 가능성, 또는 결제 불능
- 심각도 P2: 핵심 기능의 부분 중단, 다수 고객 영향, 우회 방법 존재
- 심각도 P3: 제한된 고객 영향, 비핵심 기능 오류, 명확한 우회 방법 존재
- P1 최초 응답: 10분 이내, 상태 공지: 20분 간격, 책임자: incident-commander
- P2 최초 응답: 30분 이내, 상태 공지: 60분 간격, 책임자: service-owner
- P3 최초 응답: 영업일 4시간 이내, 상태 공지: 중요 변경 시, 책임자: on-call
- 모든 장애는 `incident_id`, 발견 시각, 영향, 담당자, 조치, 종료 시각을 기록한다.
- P1과 P2는 종료 후 3영업일 이내에 원인·영향·재발 방지책을 포함한 회고를 작성한다.
- 확인되지 않은 원인이나 복구 시각을 사실처럼 공지하지 않는다.
- 고객 공지에는 현재 영향, 확인된 사실, 사용 가능한 우회 방법, 다음 공지 시각을 포함한다.
